#+TITLE: 为什么说程序员不断提高技术可能是误区？

* 从三个方面来说

1、技术是手段而非目的：
技术是解决问题的工具，而不是职业发展的最终目标，一味地追求技术的提升而忽视技术服务于业务的本质，从而导致技术与业务需求脱节。

2、市场需求变化：
it行业技术更新速度快，市场对技术人才的需求是多变的，仅仅追求技术深度可能无法满足市场对于多样化技术组合的需求，现在若能多了解一些时下最新的技术，比如最近火得不行的大模型相关，就可能有更多的机会。

3、忽视软技能的培训养：
沟通能力、写作能力、团队合作、时间管理等软技能对于程序员职业发展同样重要，过分的去关注技术提升可能会忽视这些能力的提升，而实际上程序员的职业发展，并非只有技术这么一条路径，技术管理、产品经理、咨询等多元化的发展路径，同样可以带来职业的成功，提升软技能可以让你有更多的选择。


* 其他人的想法

技术研发人员生活在 API 之下，被平台的产品或者服务调用，但是只有生活在 API 之上才有可能捕获到最大利益。
各大技术公司也要努力的生活在 API 之上，靠近直接用户服务，才有垄断的基础。
微信生活在 Android API 之上，Android 生活在 Linux API 之上，Linux 生活在芯片（ARM）之上。微信处于 API 调用链的最上层，捕获到了最大利润，芯片（ARM）生活在 API 最底层，技术门槛最高，利润捕获的最少。
Google 生活在 Windows API 之上，Windows 生活在 x86 芯片 API 之上，Google 捕获了最大利润。


有一个问题，我反复跟你们科普，结果我发现不仅普通人不懂，连一些VC都不懂，好像只有高晓松跟我能达成共识：

中国互联网的本质，是吃硅谷的技术剩饭，

但是无论是阿里、拼多多还是抖音，巨头们在对社会和商业革命的角度上，吃的是百年发达的美国消费零售的剩饭，是沃尔玛、costco、bestbuy的剩饭。

一个显而易见的例子是，YouTube在美国靠卖电话卡、保险、大学等等服务行业广告为生，Netflix和HBO靠收会员费为生，

而无论是B站、爱奇艺、腾讯视频等等，靠收会员费都被证明是一条不赚钱的路——人均GDP刚刚1万刀，月薪3000的14亿人口国家，交你妈的会员费呢。

而抖音能成功的原因，是因为它变成了中国四大电商之一，抖音最成功的商业化，就是卖货，

而无论是阿里系，京东，拼多多，抖音，真正成功的原因，都是成为了中国的沃尔玛、costco、bestbuy，让你小到水果蔬菜，大到衣食住行，全都在商城里消费，

而这是美国tech industry做不到的，无论是Amazon还是ebay，在美国都远远比不了walmart、costco等企业，凭借互联网优势，也只能比社区的kroger、safeway等等强，

原因很简单，高晓松讲过这个问题，就是中国在城市化的进程中，没有及时孵化孕育出中国的沃尔玛、costco、bestbuy、kroger、safeway，于是让互联网公司捷足先登，先把14亿人的消费零售的生态位给抢过来了。

于是美国线下零售消费，是一个个连锁大超市、大bestbuy，

中国零售消费全转成了线上，于是形成了阿里、京东、拼多多、抖音商城、快手、美团六大互联网门派。

除此之外还有两个奇葩， 一个是腾讯和米哈游的游戏充值，在全世界独树一帜地牛逼；

另一个是所有的付费SaaS，包括飞书、钉钉等等，作为14亿人的大市场，在人均GDP一万刀、人均月薪3000的大背景下，在全球也是最差的：

连飞书都不愿意付费使用，一个个企业还在为了用免费版不断用60分钟断线重连的会议功能——搞得飞书这个国内最大的SaaS团队连人均50的会费都收不上来，在全球SaaS这个市场里属于丢人现眼。

我为什么要跟你讲这个故事？

我发现很多互联网从业者，主要是那些在自己一亩三分地干干活、吃了红利、两耳不闻窗外事的牛马们，

对中国互联网有不切实际地幻想，以为一直吃硅谷剩饭，就可以一直增长，中国互联网就能两三年后复苏，就能再孵化出3个腾讯，5个阿里，8个拼多多，20个美团，

这样自己就能不断跳槽，继续财务自由的美梦了。

——抱歉，这种幻想是纯粹的狗屁，中国互联网行业的上限，就是中国消费零售的上限，天花板焊死了，就是阿里、京东、拼多多、抖音商城、快手、美团六大门派。

没有其他红利了，也做不起来SaaS，更不可能有AI红利——人均GDP一万刀、月薪3000的群体，用你妈的SaaS，用你妈的AI产品呢，都不可能给你付费的。

天天想着跳槽、创业、继续财务自由的朋友们，如果不想着游戏出海、AI出海、开源出海，天天还想着在墙内洼地吃移动互联网的红利，

继续跳跳槽就能年薪50万涨到200万，200万直接创业8位数，然后变成下一个张一鸣、马云，

显然在2024年来看，在目前消费零售的天花板锁死、宏观经济没有任何好转的状况下，就是纯粹的痴人说梦了。
